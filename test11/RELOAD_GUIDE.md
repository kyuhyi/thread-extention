# 확장프로그램 완전 재로드 가이드

## 🔄 문제 상황
기존 오류 메시지가 계속 표시되는 경우, 브라우저가 이전 버전을 캐시하고 있기 때문입니다.

## ✅ 완전 재로드 방법

### 1단계: 기존 확장프로그램 완전 삭제
1. Chrome/Whale에서 `chrome://extensions` 또는 `whale://extensions` 주소로 이동
2. "AI 콘텐츠 생성기" 확장프로그램 찾기
3. **"삭제" 버튼 클릭** (비활성화가 아니라 완전 삭제)
4. 브라우저 완전 종료 (모든 창 닫기)

### 2단계: 브라우저 캐시 삭제 (선택사항이지만 권장)
1. 브라우저 재실행
2. `Ctrl + Shift + Delete` (Windows) 또는 `Cmd + Shift + Delete` (Mac)
3. "캐시된 이미지 및 파일" 선택
4. "데이터 삭제" 클릭

### 3단계: 확장프로그램 새로 로드
1. `chrome://extensions` 또는 `whale://extensions` 이동
2. 우측 상단 **"개발자 모드" 토글 켜기**
3. **"압축해제된 확장 프로그램을 로드합니다" 클릭**
4. `c:\project\test11` 폴더 선택
5. 확장프로그램이 로드되면 **"새로고침" 아이콘(↻) 클릭**

### 4단계: 확인
1. 확장프로그램 아이콘 클릭
2. 유튜브 영상이 자동 재생되는지 확인
3. F12 (개발자 도구) 열어서 콘솔 탭에 오류 메시지가 없는지 확인

## 📋 체크리스트
- [ ] 기존 확장프로그램 완전 삭제
- [ ] 브라우저 완전 종료 후 재실행
- [ ] 개발자 모드 활성화
- [ ] 새로운 확장프로그램 로드
- [ ] 새로고침 버튼 클릭
- [ ] 영상 재생 및 오류 메시지 확인

## 🎯 현재 수정된 내용
1. ✅ YouTube 영상 CSP 오류 → `manifest.json`에 CSP 정책 추가
2. ✅ YouTube IFrame API 오류 → 직접 iframe 사용으로 변경
3. ✅ null 참조 오류 → null 체크 추가
4. ✅ 영상 ID 목록 → 사용자 제공 7개 영상만 사용

## ⚠️ 주의사항
- **"비활성화"가 아닌 "삭제"를 해야 합니다**
- 삭제 후 반드시 브라우저를 완전 종료했다가 재실행하세요
- 새로 로드한 후에는 반드시 "새로고침(↻)" 버튼을 클릭하세요

## 🆘 그래도 안 되면
1. 개발자 도구(F12) 열기
2. Console 탭에서 정확한 오류 메시지 확인
3. 스크린샷과 함께 오류 메시지 공유
