✨ 아이콘 사용 안내

아래 아이콘들을 스크린샷으로 캡처하여 사용하거나, 무료 아이콘 사이트에서 AI/콘텐츠 관련 아이콘을 다운로드하세요.

  1. 16x16: 브라우저 툴바 작은 아이콘
  2. 48x48: 확장프로그램 관리 페이지
  3. 128x128: 크롬 웹스토어용 (필요시)

추천 아이콘 사이트:

  • Icons8

📸 아이콘 저장 방법

  1. 이 HTML 파일을 브라우저에서 열기
  2. 각 아이콘을 우클릭 → "다른 이름으로 이미지 저장"
  3. 또는 스크린샷 도구로 정확한 크기로 캡처
  4. 파일명을 icon16.png, icon48.png, icon128.png로 저장
  5. icons 폴더에 저장
