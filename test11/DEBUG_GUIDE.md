# 확장프로그램 디버깅 가이드

## 🔍 오류 확인 방법

현재 보이는 오류들은 **웹사이트 자체의 오류**입니다 (한겨레 뉴스 사이트).
확장프로그램의 실제 오류를 확인하려면 다음과 같이 해야 합니다:

### 1단계: 확장프로그램 팝업의 콘솔 확인

1. 확장프로그램 아이콘 **우클릭**
2. **"팝업 검사"** 또는 **"Inspect popup"** 클릭
3. 새로운 개발자 도구 창이 열림 (이것이 확장프로그램 전용 콘솔)
4. Console 탭에서 확장프로그램 관련 오류 확인

### 2단계: 영상 관련 오류 확인

팝업 검사 콘솔에서 다음 메시지를 찾아보세요:

✅ **정상 작동**:
```
Video loaded: lXl0rIHo9Xo
```

❌ **오류 발생**:
```
videoPlayer element not found
Error loading video: ...
```

### 3단계: 확장프로그램 백그라운드 오류 확인

1. `chrome://extensions` 또는 `whale://extensions` 이동
2. "AI 콘텐츠 생성기" 찾기
3. **"백그라운드 페이지"** 또는 **"서비스 워커"** 링크 클릭
4. 백그라운드 스크립트 오류 확인

## 🎯 현재 상황 정리

**현재 콘솔에 보이는 오류들**:
- ❌ Chrome blocked resource → 한겨레 사이트의 광고 차단 관련
- ❌ Uncaught SyntaxError → 한겨레 사이트의 JavaScript 오류
- ❌ React error #418, #423 → 한겨레 사이트의 React 오류
- ❌ postscribe error → 한겨레 사이트의 광고 스크립트 오류
- ❌ CORS policy error → 한겨레 사이트의 외부 리소스 로드 오류
- ✅ Content script 로드됨 → 우리 확장프로그램은 정상 로드됨!

**확인 필요**:
- 확장프로그램 팝업을 열었을 때 영상이 재생되는지
- 팝업 검사 콘솔에서 "Video loaded: ..." 메시지가 보이는지

## 🚀 테스트 방법

### 영상 재생 테스트
1. 아무 웹페이지 열기
2. 확장프로그램 아이콘 클릭
3. 팝업이 열리면서 유튜브 영상이 자동 재생되어야 함
4. 영상이 보이지 않으면 → 팝업 우클릭 → "팝업 검사" → 콘솔 오류 확인

### 콘텐츠 생성 테스트
1. 뉴스 기사 페이지 열기
2. 확장프로그램 팝업 열기
3. "🚀 이 페이지 콘텐츠 분석하기" 클릭
4. 로딩 후 3가지 콘텐츠 생성 확인
5. 오류 발생 시 → 팝업 검사 콘솔에서 오류 확인

## 💡 자주 발생하는 문제

### 문제 1: 영상이 안 보임
**증상**: 팝업 열었는데 영상 영역이 비어있음
**확인**: 팝업 우클릭 → 팝업 검사 → 콘솔에서 "Video loaded" 메시지 확인
**해결**: 새로고침(↻) 후 재시도

### 문제 2: API 오류
**증상**: "콘텐츠 생성 오류" 메시지 표시
**확인**: 팝업 검사 → Console 또는 Network 탭에서 API 응답 확인
**해결**: API 키 재확인, 네트워크 연결 확인

### 문제 3: 콘텐츠 추출 실패
**증상**: "페이지 내용을 가져올 수 없습니다" 오류
**확인**: 팝업 검사 → 콘솔에서 content script 관련 오류 확인
**해결**: 페이지 새로고침 후 재시도

## 📸 스크린샷 가이드

오류 보고 시 다음을 캡처해주세요:
1. 확장프로그램 팝업 화면
2. **팝업 우클릭 → 팝업 검사** 후 열린 콘솔 화면
3. 백그라운드 페이지 콘솔 (있는 경우)
