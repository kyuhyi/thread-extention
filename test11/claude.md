# 크롬/웨일 확장프로그램 개발 요청: 콘텐츠 아이디어 생성기

## 프로젝트 개요
현재 읽고 있는 웹페이지의 텍스트를 선택하면, Gemini 2.5 Flash API를 활용하여 3가지 포맷의 콘텐츠를 자동 생성해주는 팝업형 브라우저 확장프로그램을 만들어주세요.

## 핵심 기능

### 1. 콘텐츠 생성 기능
사용자가 웹페이지에서 텍스트를 선택(드래그)하고 확장프로그램 아이콘을 클릭하면:
- **유튜브 숏츠 시나리오**: 60초 분량의 대본 1개 (후킹 멘트, 전개, 클로징 구조)
- **블로그 게시글**: 2000자 내외의 완성된 포스팅 1개 (제목, 본문, 해시태그 포함)
- **스레드 짧은 글**: 조회수가 터질 만한 임팩트 있는 짧은 글 1개 (150-300자)

### 2. API 키 관리 시스템
- 확장프로그램 첫 실행 시 API 키 입력 화면 표시
- Gemini API 키 발급 URL 명확히 표시: `https://aistudio.google.com/app/apikey`
- 입력된 API 키는 Chrome/Whale의 `chrome.storage.local`에 안전하게 저장
- 한 번 입력한 API 키는 다시 입력할 필요 없음
- 설정 화면에서 API 키 수정/삭제 가능

### 3. 사용자 인터페이스
**팝업 UI 구성:**
- 헤더: 로고 + 설정 버튼
- API 키 입력란 (최초 1회 또는 미설정 시)
- "선택한 텍스트로 콘텐츠 생성" 버튼
- 로딩 상태 표시
- 결과 표시 영역 (3가지 포맷 탭 구분)
- 각 결과마다 "복사하기" 버튼

**디자인 요구사항:**
- 깔끔하고 모던한 디자인
- 반응형으로 팝업 크기에 맞게 조정
- 한국어 UI
- 로딩 시 애니메이션 표시

## 기술 스펙

### 필수 파일 구조
```
content-idea-generator/
├── manifest.json (Manifest V3)
├── popup.html
├── popup.js
├── content.js (텍스트 선택 감지)
├── background.js (API 호출 처리)
├── styles.css
└── icons/
    ├── icon16.png
    ├── icon48.png
    └── icon128.png
```

### Manifest V3 필수 권한
```json
{
  "manifest_version": 3,
  "permissions": [
    "storage",
    "activeTab",
    "scripting"
  ],
  "host_permissions": [
    "https://generativelanguage.googleapis.com/*"
  ]
}
```

### Gemini API 연동
- API 엔드포인트: `https://generativelanguage.googleapis.com/v1beta/models/gemini-2.0-flash-exp:generateContent`
- 메소드: POST
- 헤더: `Content-Type: application/json`
- API 키는 URL 쿼리 파라미터로 전달: `?key=YOUR_API_KEY`

### 프롬프트 엔지니어링
선택된 텍스트를 분석하여 다음 3가지를 생성할 때 사용할 프롬프트 템플릿:
```
당신은 1인 지식사업가를 위한 콘텐츠 전문가입니다.
다음 원문을 바탕으로 3가지 포맷의 콘텐츠를 생성해주세요.

[원문]
{선택된 텍스트}

[생성 요청]
1. 유튜브 숏츠 시나리오 (60초 분량):
   - 첫 3초 후킹 멘트
   - 핵심 내용 전달 (40초)
   - 강력한 클로징 CTA (17초)
   - 자막으로 표시될 대본 형식

2. 블로그 게시글 (2000자 내외):
   - SEO 최적화된 제목
   - 서론-본론-결론 구조
   - 읽기 쉬운 문단 구성
   - 관련 해시태그 3-5개

3. 스레드 짧은 글 (150-300자):
   - 첫 문장에 강력한 임팩트
   - 호기심 유발
   - SNS 확산 가능한 톤앤매너
   - 이모지 적절히 활용

각 콘텐츠는 명확히 구분하여 JSON 형식으로 응답해주세요:
{
  "shorts_script": "...",
  "blog_post": "...",
  "thread_post": "..."
}
```

## 구현 우선순위

### Phase 1: 기본 구조
1. Manifest V3 기반 확장프로그램 뼈대 구축
2. 팝업 UI 기본 레이아웃
3. API 키 저장/불러오기 기능

### Phase 2: 핵심 기능
1. 웹페이지 텍스트 선택 감지
2. Gemini API 호출 및 응답 처리
3. 3가지 포맷 결과 화면 표시

### Phase 3: UX 개선
1. 로딩 상태 UI
2. 에러 핸들링 (API 키 오류, 네트워크 오류 등)
3. 복사 기능
4. 결과 탭 전환 UI

## 에러 처리
- API 키 미입력 시: 입력 안내 메시지
- API 키 오류 시: 키 확인 요청 + 발급 URL 재표시
- 텍스트 미선택 시: "텍스트를 선택해주세요" 안내
- API 응답 오류 시: 재시도 버튼 제공
- 네트워크 오류 시: 명확한 오류 메시지

## 추가 요구사항
- 모든 텍스트는 한국어
- 아이콘은 간단한 AI 콘텐츠 생성 이미지 (직접 생성 또는 placeholder)
- 코드는 주석을 한국어로 작성
- 확장프로그램 이름: "AI 콘텐츠 생성기" 또는 "바이브 콘텐츠 메이커"

## 테스트 시나리오
1. 확장프로그램 설치 후 첫 실행 → API 키 입력 화면 표시
2. API 키 입력 후 저장 → 다음 실행 시 자동 로드
3. 웹페이지에서 텍스트 선택 → 확장프로그램 클릭 → 3가지 콘텐츠 생성
4. 각 결과 복사 버튼 클릭 → 클립보드 복사 확인
