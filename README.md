# AI 콘텐츠 생성기 1.3.1

유튜브 숏츠, 블로그, 스레드 글을 생성하는 Chrome 확장입니다. 블로그에는 ChatGPT 계정으로 로그인한 로컬 Codex CLI를 통해 웹툰 이미지 4~5장을 생성하고 문단 사이에 넣습니다.

- 숏츠: 짧은 호흡으로 줄바꿈하고 문단과 빈 줄을 표시·복사에 동일하게 적용합니다.
- 스레드: 첫 줄에 숫자를 포함하고 최대 18자, 빈 줄 하나 뒤에 짧은 본문을 작성합니다.
- 블로그: 이미지 생성 진행률을 저장하고, 완료된 글과 이미지를 함께 복사합니다. 네이버 본문에 붙여넣으면 사진을 순서대로 첨부하고 왼쪽 정렬을 적용합니다.
- 글 생성에는 Gemini API 키를 사용합니다. 이미지 생성에는 로그인된 Codex 계정 사용량이 적용됩니다.

## 실행

1. Python과 Node.js, Codex CLI를 준비하고 `pip install -r requirements.txt`를 실행합니다.
2. `codex login`으로 ChatGPT 계정에 로그인합니다.
3. `start_server.bat` 또는 `python -B server.py`로 로컬 서버를 실행합니다.
4. Chrome 확장 관리에서 개발자 모드를 켜고 **manifest.json이 있는 이 저장소 폴더**를 로드합니다.
5. 팝업에서 Gemini API 키와 필요한 네이버 검색 설정을 입력합니다. 개인 설정과 키는 커밋하지 않습니다.

코드를 업데이트한 뒤에는 확장, 큰 화면, 네이버 글쓰기 페이지를 새로고침합니다. 네이버 글쓰기 페이지를 열어둔 상태에서 `글+이미지 복사`를 누르고 **본문**에 Ctrl+V를 한 번 누른 뒤 완료 안내를 기다립니다. 제목 칸은 따로 입력합니다.

자세한 내용은 [블로그 웹툰 사용 가이드](BLOG_WEBTOON_GUIDE.md)를 참고하세요. 자동 테스트는 `npm test`로 실행합니다. Python 캐시가 확장 로드를 막지 않도록 `-B` 옵션을 사용합니다.

네이버에서는 시험용 수신기 코드로 글+이미지 5장의 한 번 붙여넣기 및 임시저장 후 재열기를 검증했습니다. 설치된 확장의 연결 검사와 localhost 중계는 업데이트 적용 후 사용 환경에서 확인이 필요합니다.

## 초기 버전 안내

아래는 초기 기능 설명입니다. 설치와 현재 동작은 위 안내 및 블로그 웹툰 사용 가이드를 우선합니다.

Gemini 2.5 Flash API를 활용하여 웹페이지의 선택한 텍스트로 유튜브 숏츠, 블로그 게시글, 스레드 짧은 글을 자동 생성하는 크롬/웨일 확장프로그램입니다.

## 🎯 주요 기능

- **유튜브 숏츠 시나리오**: 60초 분량의 완성된 대본 (후킹, 전개, 클로징 구조)
- **블로그 게시글**: 2000자 내외의 SEO 최적화된 포스팅 (제목, 본문, 해시태그)
- **스레드 짧은 글**: 임팩트 있는 SNS용 짧은 글 (150-300자)

## 📦 설치 방법

### 1. API 키 발급

1. [Google AI Studio](https://aistudio.google.com/app/apikey)에 접속
2. Google 계정으로 로그인
3. "Get API Key" 또는 "Create API Key" 클릭
4. 생성된 API 키 복사 (예: `AIzaSy...`)

### 2. 확장프로그램 설치 (개발자 모드)

#### Chrome/Edge 브라우저:
1. 브라우저 주소창에 `chrome://extensions/` 입력
2. 우측 상단의 **"개발자 모드"** 토글 활성화
3. **"압축해제된 확장 프로그램을 로드합니다"** 클릭
4. 이 프로젝트 폴더(`test11`) 선택
5. 확장프로그램이 설치되면 툴바에 아이콘 표시됨

#### Whale 브라우저:
1. 브라우저 주소창에 `whale://extensions/` 입력
2. 우측 상단의 **"개발자 모드"** 체크박스 활성화
3. **"압축해제된 확장기능 로드"** 클릭
4. 이 프로젝트 폴더(`test11`) 선택
5. 확장프로그램이 설치되면 툴바에 아이콘 표시됨

### 3. 아이콘 설정 (선택사항)

현재 아이콘 파일이 없으면 확장프로그램이 기본 아이콘으로 표시됩니다.
커스텀 아이콘을 사용하려면:

1. `icons` 폴더에 다음 파일 준비:
   - `icon16.png` (16x16px)
   - `icon48.png` (48x48px)
   - `icon128.png` (128x128px)

2. 추천 아이콘 사이트:
   - [Flaticon](https://www.flaticon.com) - "AI", "content", "magic" 검색
   - [Icons8](https://icons8.com) - 무료 PNG 다운로드
   - [IconScout](https://iconscout.com) - 다양한 스타일

3. 또는 `icons/icon-generator.html` 파일을 브라우저에서 열어 임시 아이콘 확인

## 🚀 사용 방법

### 첫 실행 시

1. 브라우저 툴바에서 확장프로그램 아이콘 클릭
2. "API 키 설정" 화면에서 발급받은 Gemini API 키 입력
3. **"저장"** 버튼 클릭
4. API 키는 안전하게 로컬에 저장되며, 다음 실행 시 자동으로 로드됨

### 콘텐츠 생성

1. 벤치마킹하고 싶은 웹페이지(블로그, 뉴스 등)로 이동
2. 브라우저 툴바에서 확장프로그램 아이콘 클릭
3. **"🚀 이 페이지 콘텐츠 분석하기"** 버튼 클릭
   - 텍스트 선택 불필요! 페이지 전체를 자동으로 분석합니다
   - 원한다면 특정 텍스트를 선택한 상태로 클릭하면 그 부분만 분석합니다
4. 잠시 기다리면 3가지 포맷의 콘텐츠가 생성됨
5. 탭을 전환하며 각 콘텐츠 확인
6. **"📋 복사"** 버튼으로 원하는 콘텐츠 클립보드에 복사

### API 키 변경/삭제

1. 확장프로그램 팝업 우측 상단의 **⚙️ 설정** 버튼 클릭
2. API 키 입력란에 새 키 입력 후 **"저장"**
3. 또는 기존 키 삭제 후 저장

## 🔧 기술 스택

- **Manifest V3**: 최신 크롬 확장프로그램 표준
- **Gemini 2.5 Flash API**: Google의 최신 생성형 AI
- **Chrome Storage API**: 안전한 로컬 데이터 저장
- **Vanilla JavaScript**: 프레임워크 없는 가볍고 빠른 구현

## ⚠️ 문제 해결

### "API 키가 올바르지 않습니다" 오류
- API 키를 정확히 복사했는지 확인
- [Google AI Studio](https://aistudio.google.com/app/apikey)에서 키 상태 확인
- 키가 만료되었다면 새로 발급

### "텍스트를 먼저 선택해주세요" 메시지
- 웹페이지에서 텍스트를 드래그하여 선택한 후 확장프로그램 실행
- 너무 짧은 텍스트(1-2단어)는 피하고, 최소 한 문단 이상 선택

### "네트워크 오류" 메시지
- 인터넷 연결 상태 확인
- 방화벽이나 프록시 설정 확인
- Gemini API 서비스 상태 확인

### 확장프로그램이 로드되지 않음
- `manifest.json` 파일이 프로젝트 루트에 있는지 확인
- 브라우저 콘솔(F12)에서 오류 메시지 확인
- 브라우저를 재시작하고 다시 로드

### 생성된 콘텐츠가 이상함
- 선택한 원문 텍스트가 충분히 의미 있는 내용인지 확인
- 너무 짧거나 불완전한 문장은 피하기
- 다시 생성 버튼을 눌러 재시도

## 🔐 보안 및 개인정보

- API 키는 사용자의 로컬 브라우저 저장소에만 저장됨
- 외부 서버로 API 키가 전송되지 않음
- 선택한 텍스트는 Gemini API로만 전송되며, 별도 저장되지 않음
- Chrome Storage API는 암호화된 저장소 사용
